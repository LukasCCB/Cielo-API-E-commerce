# Google Pay

O Google Pay é uma carteira virtual que permite que o comprador faça pagamentos seguros em lojas virtuais e apps usando seus cartões de crédito e débito armazenados em suas contas Google e dispositivos Android.

## Pré-requisitos

Para usar o Google Pay, é necessário que a loja já possua cadastro e integração Google Pay. Além disso, você deve:

1. Concordar com os termos de serviço do Google Pay;
2. <a href="https://docs.cielo.com.br/ecommerce-cielo/docs/integracao-com-google-pay" target="_blank">Integrar com a Google Pay</a>;
3. Contratar a API E-commerce Cielo;
4. Contratar o Cielo 3.0 como adquirência;
5. <a href="https://docs.cielo.com.br/ecommerce-cielo/docs/transacao-google-pay" target="_blank">Criar transação com Google Pay na API E-commerce Cielo</a>;
6. <a href="https://docs.cielo.com.br/ecommerce-cielo/docs/solicitacao-de-dados-de-producao" target="_blank">Solicitar dados de produção</a>.
