# Extrato Pix

No **Extrato Pix**, você pode acompanhar as movimentações da sua conta Pix na Cielo, incluindo recebimentos, devoluções, tarifas, bloqueios e transferências realizadas.

Use os filtros disponíveis para localizar transações específicas e consultar os detalhes de cada operação.

<Image src="https://files.readme.io/165bfbf30f51ff8b58d17189ef5e54aae01024272a1845bdb100475497bd7421-extrato_pix.png" align="center" />

Para consultar os detalhes de uma transação, clique em **Mais detalhes**.

Ao consultar uma transação, é possível também baixar seu comprovante ou solicitar uma devolução:

<Image src="https://files.readme.io/4e67548c13b70a27f21366559ccd62882b42a4ab0f8d4b4c34985485617fcae7-detalhes_pix.png" align="center" />
