# Configurações

A área de **Configurações** centraliza os recursos utilizados na configuração e gerenciamento da integração com a API E-commerce Cielo.

Por meio dessa área, é possível:

* Configurar URLs de notificações;
* Gerenciar IPs confiáveis;
* Administrar credenciais da integração.
