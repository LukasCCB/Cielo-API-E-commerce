# Contestar chargeback pelo site Cielo ou API

## Via site Cielo

Para realizar uma contestação de chargeback via site Cielo, siga as instruções:

1. Acesse o site **Cielo > Vendas** e clique em **Contestação de Vendas**.

![Tela site Cielo](https://files.readme.io/ea53f6e12fd1cc96e4abcd23270607ad074527163e80fd12e88e36ae5612bb09-image.png)

2. Pronto, agora você já pode visualizar as contestações das suas vendas.

<Image align="center" width="550px" src="https://files.readme.io/ca0fc298670595746cbfbc4d3430759233850b0bc58b8bbf036c4b4ea4679b47-Constestao_-_1.png" caption="Tela de contestações de vendas" />

## Via API de chargeback

Caso queira realizar a aceitação ou a contestação de vendas via API, acesse a  <a href="https://developercielo.github.io/manual/api-chargeback-2-0" target="_blank">API de Chargeback</a>.
