Pelo site Cielo, é possível editar os seguintes dados de uma cobrança recorrente:

* Dados de agendamento;
* Endereço de cobrança;
* Endereço de entrega.

<Callout icon="ℹ️" theme="info">
  ### Permissões necessárias

  As configurações indicadas só podem ser realizadas por usuários com permissões de **Administrador** ou **Analista**.

  Para gerenciar permissões de acesso, acesse **Meu cadastro >&#x20;**<Anchor target="_blank" href="https://docs.cielo.com.br/ecommerce-cielo/docs/gestao-de-acessos">**Gestão de acessos**</Anchor>.
</Callout>

1. Acesse o site Cielo, clique em **E-commerce** > **Gestão de Recorrência**
2. Você irá visualizar a tela **Minhas recorrências**, com a lista de todas as recorrências criadas. Para ver **mais detalhes de uma cobrança recorrente** específica, clique na **seta azul** na linha da recorrência:

<Image align="center" src="https://files.readme.io/c8859edd16285df96980dbd63a19449a739fef895000d04da2ccbdb229531199-Central_de_relatrios_-_Desktop.png" />

## Editar uma recorrência

4. Ao clicar na seta azul, você irá visualizar os detalhes da cobrança recorrente selecionada. Clique em **Editar** no bloco de informações que deseja alterar:

* Dados de agendamento;
* Endereço de cobrança;
* Endereço de entrega.

<Image align="center" src="https://files.readme.io/a9145592df9efff383fba50bb63a630cff9d3fe00931d404814d1d7864151de1-gestao_recorrencias_-_editar.png" />

Nessa mesma tela você pode visualizar o histórico de transações daquela cobrança recorrente:

<Image align="center" src="https://files.readme.io/2e122ca98ed93c0684f427c74bc2b30e340ce356a89db1b239136a446328ac95-gestao_recorrencias_-_historico.png" />

5. Após editar as informações da recorrência, a tela irá exibir um alerta para confirmar o prosseguimento:

<Image align="center" src="https://files.readme.io/a5a5cc015e270d33f2551e47e2d94200b051d3c335cacc16244b816196b586b5-Modal_-_alerta.png" />

<br />

6. Para confirmar, é necessário realizar a autenticação em duas etapas. Insira o token que foi enviado para você via app Cielo Gestão ou e-mail e clique em **Autenticar**:

<Image align="center" src="https://files.readme.io/1a22aad71a1f6c82077c0e24df27579778cc0959ab63a1485abda50634e0c17d-image.png" />

<br />

7. Pronto, a sua recorrência foi editada com sucesso:

<Image align="center" src="https://files.readme.io/434eeadeb8174525a0205278f5f100acf798c8733c2b60609c3fef90be17708b-Modal_-_sucesso.png" />
