# Dados de cadastro

Após fazer login e selecionar o EC, clique em **Meu cadastro** para conferir e alterar os dados do estabelecimento, usuário e conta.

### Dados do estabelecimento

Em **Dados do estabelecimento** > **Estabelecimento**, você pode conferir os dados da empresa e endereço:

<Image align="center" src="https://files.readme.io/f30524c02f7c3a00de8b6883f92f4107ea424162e3af6d003ef46e3faf5d3d57-dados_de_estabelecimento.png" />

Em **Dados do estabelecimento** > **Contato**, você pode conferir os dados de contato do estabelecimento:

<Image align="center" src="https://files.readme.io/99740f57d70cec0a183741d15c84c05c9f6bf6a368d83507de803d444ecfb7a1-dados_de_contato.png" />

Em **Dados do estabelecimento** > **Proprietário**, você pode conferir os dados do proprietário do cadastro do estabelecimento comercial:

<Image align="center" src="https://files.readme.io/3f760aee890fc8bf03a07f11694fa4c255bd5aa8bb981ea7704c95a50186309e-dados_do_proprietario.png" />

### Dados do usuário

Em **Meu cadastro** > **Dados do usuário**, você pode conferir os dados do usuário logado no momento:

<Image align="center" src="https://files.readme.io/3bd8f7e3e00d85c3478da70553a6f03cf4fb85a5b1c5f50b9917c5c7ee986944-dados_do_usuario.png" />

No ícone de edição ao lado de **Senha**, é possível alterar a sua senha de login.
