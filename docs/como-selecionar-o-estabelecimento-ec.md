# Como selecionar o estabelecimento (EC)

Caso tenha mais de um estabelecimento (EC) cadastrado na Cielo, é importante que você selecione o estabelecimento correto para a ação que deseja executar no site Cielo.

Caso precise trocar o estabelecimento, siga os passos a seguir:

1. Na <Anchor label="área logada do site Cielo" target="_blank" href="https://www.cielo.com.br/">área logada do site Cielo</Anchor> , clique em **Meus estabelecimentos**:

<Image border={false} src="https://files.readme.io/523c3e9212f349e484e116e19884a2001977e0be6935ae13c733644152d5eaea-image.png" />

3. Clique em **Ver mais**;

<Image align="center" border={false} width="600px" src="https://files.readme.io/09bac7f5678805a14fa346627dafe01198b4d73ccb36f024b425a28d5a120c32-Captura_de_tela_2025-01-14_094338.png" />

4. Selecione o estabelecimento desejado, (*O número de EC da API Cielo E-commerce pode ser encontrado no e-mail de boas-vindas enviado pela Cielo*) e clique em **Acessar**;

<Image align="center" border={false} width="550px" src="https://files.readme.io/99f935438ccaaaf54820eb3b4844a96e581e8ebedebe717c3cfc627bc97a0c7b-Captura_de_tela_2025-01-14_095222.png" />
