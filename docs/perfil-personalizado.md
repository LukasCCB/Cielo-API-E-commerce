# Perfil personalizado

Use essa opção para criar um perfil com **permissões específicas** e aplicá-lo a usuários.

A criação do perfil personalizado é feita em etapas:

1. Definir o nome do perfil;
2. Configurar as permissões de acesso;
3. Informar usuários (opcional);
4. Revisar as informações;
5. Confirmar os estabelecimentos.

Siga as instruções abaixo para concluir o processo.

## Definir nome do perfil

1. Informe o nome do perfil;
2. Clique em **Próximo**.

<Image align="center" width="600px" src="https://files.readme.io/2b184cdf9ed94a884bb2ea6b2cdfd94219bda6dd99b24ea0ed877febb50fd24b-image.png" />

## Configurar permissões

1. Selecione as permissões para cada funcionalidade;
2. Defina o tipo de acesso:
   * **Visualizar**;
   * **Visualizar e executar**;
3. Clique em **Próximo**.
4. Insira o **token de segurança** gerado no **App Cielo Gestão**.

<Image align="center" width="400px" src="https://files.readme.io/9062907d7e51015a602c8b0415a7961eedf82e6366f00663034ed894576581d8-Selecionar_func_1.png" />

<Image align="center" width="400px" src="https://files.readme.io/f08f6bfadeeca90d4f6db98a3600ae77b4dd44d22e16ea4fca8ff18dd766a40b-Selecionar_func_2.png" />

<Image align="center" width="400px" src="https://files.readme.io/e9688d144710b5b217dcd4b53fbcdfeb99645584351742129b111b623d14dfba-Selecionar_func_3.png" />

## Atribuir usuários ao perfil

1. Escolha se deseja atribuir usuários ao perfil;
2. Caso deseje:
   * Informe **CPF** e **e-mail**, ou;
   * Utilize a opção em **Preencher em lote**;
3. Clique em **Próximo**.

<Image align="center" width="600px" src="https://files.readme.io/e875810cd53a20aa05a971e53398235e4347d228822da8d5740b0fe93cc0c966-image.png" />

## Revisar perfil

1. Confira as permissões e informações configuradas;
2. Clique em **Próximo**.

<Image align="center" src="https://files.readme.io/3ae6205849e02c6130748cfe63fc236c6d6eafc17482e51a0c2764e5230f7bf3-Verificar_func_disponibilizadas.png" />

## Confirmar estabelecimentos

1. Verifique os estabelecimentos aos quais o perfil terá acesso;
2. Clique em **Próximo**.

<Image align="center" width="600px" src="https://files.readme.io/5b9c27a594332facbb2d8477a585473e5742f52a4e90cc2ec36a4a1453a30273-Confirmar_perfil_e_estabelecimento_do_usuario_.png" />

## Concluir criação

Após a confirmação:

* O perfil é criado;
* Se foram informados usuários, os convites são enviados.

A pessoa convidada deve acessar o e-mail informado para **concluir o cadastro e ativar o acesso**.

O convite expira em **até 3 dias**.
