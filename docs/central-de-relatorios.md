# Central de relatórios 

A Central de Relatórios está disponível para que você consulte os principais relatórios relacionados às suas transações e configurações.

| **Relatórios**         | **Descrição**                                                    |
| ---------------------- | ---------------------------------------------------------------- |
| Transações detalhadas  | Relatório completo com todas as transações e seus detalhes.      |
| Transações de boleto   | Transações realizadas com a forma de pagamento boleto.           |
| Transações recorrentes | Lista com detalhes de transações com informações de recorrência. |

<Callout icon="⚠️" theme="warn">
  ## Atenção

  * Os relatórios disponíveis na Central de Relatórios são exclusivos para clientes da API E-commerce Cielo;
</Callout>

## Central de Relatórios

Para acessar a central de relatórios, siga os passos abaixo:

1. Acesse o [site Cielo](https://minhaconta2.cielo.com.br/site/acessos/login) ;

<Image
  src="https://files.readme.io/202788f668108799c523d99175ea04e38e353f73f96cff1658752e24971be5db-Site_Cielo_GIF.gif"
  alt="Site Cielo GIF"
  align="center"
  width={500}
/>

2. Verifique se o estabelecimento atual é o que você deseja extrair relatórios:

<Image align="center" src="https://files.readme.io/c07be491e6cda0cca1b6068d885878c39570d43255ebfd9f146b6ed7dcc8b0c8-1.png" />

<Callout icon="ℹ️">
  Acesse [Como selecionar o estabelecimento (EC)](https://docs.cielo.com.br/ecommerce-cielo/docs/como-selecionar-o-estabelecimento-ec) para saber como selecionar o estabelecimento comercial 
</Callout>

3. Clique em **E-commerce**;

![](https://files.readme.io/0f0d434a663f00560559bba27ba0284a1946c688efee0986c97fd65ee608b95a-image.png)

4. Clique em **Central de Relatórios**;

![](https://files.readme.io/5fa5a57bfbdfc3cb2009f0f3d40c2e1fdda5cfd42ad73ec0578fa47aa8df8601-image.png)

5. Clique no relatório que você deseja visualizar;

![](https://files.readme.io/5be25912c430582484ea4bb6e1b147832aaf386bdf1700c400ae9c78bcb8bd39-image.png)

6. Escolha entre as opções de período que deseja contemplar em seu relatório. Para personalizar as datas, clique em **Personalizado**. Clique em **Solicitar**.

<Image align="center" src="https://files.readme.io/c824ef0e795c0ab5775e71ce104df01e4bb8c10b1139333b00451bb886f4d423-2.png" />

<Callout icon="⚠️" theme="warn">
  Um e-mail com o link para o download do relatório será enviado para o e-mail cadastrado na sua conta. O link é válido por 24 horas. Após esse período, o relatório poderá ser acessado no **Histórico de Relatórios** por até 90 dias.
</Callout>

## Histórico de relatórios

1. Para acessar o histórico, clique em **Histórico de relatórios**;

![](https://files.readme.io/f355a40b6d9e0e1bd68c93d9a80a869e580cbcd90281cb24f16879854d6a8138-image.png)

2. Você pode baixar os relatórios gerados e ver os detalhes.

<Image align="center" src="https://files.readme.io/07ba56f56c4e7b202f237c1f2da28800d83f59087e277799e359d60bd8978bee-3.png" />

Para aplicar filtros às informações, clique em **Filtros**.
