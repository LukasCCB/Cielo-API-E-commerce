# Transações

A área de **Transações** reúne as vendas realizadas pelo seu estabelecimento na API E-commerce Cielo.

Nesta área, você pode **consultar transações**, acessar os detalhes de cada venda e realizar ações como **captura, cancelamento, estorno, devolução Pix e conciliação de boletos**.

## Como acessar

1. Acesse o <Anchor target="_blank" href="https://www.cielo.com.br/">Site Cielo</Anchor>;
2. Selecione o estabelecimento (EC) desejado;
3. No menu superior, clique em **E-commerce**;
4. Acesse **Transações**.
