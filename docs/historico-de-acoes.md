# Histórico de ações

O **Histórico de ações** permite acompanhar as alterações realizadas na Gestão API E-commerce.

Por meio dessa funcionalidade, é possível consultar registros relacionados a configurações, microsserviços, carteiras digitais e outras operações realizadas no ambiente.

<Callout icon="📘" theme="info">
  ### Importante

  O Histórico de ações não exibe eventos relacionados à geração e ao gerenciamento de credenciais.

  Para consultar essas informações, acesse o histórico disponível na área [Credenciais](https://docs.cielo.com.br/ecommerce-cielo/docs/revogar-e-criar-credenciais-no-site-cielo).
</Callout>

## Como acessar

1. Selecione o estabelecimento (EC) desejado;
2. No menu superior, clique em **E-commerce**;
3. Acesse **Gestão API E-commerce**;
4. Clique em **Histórico de ações**.

![](https://files.readme.io/987054860ef44e7439a4d2b584b1f7fd3cf17da6df0382929c6c07316821ac96-Historico_de_aoes.png)

## Consultar ações

A lista apresenta as ações realizadas no ambiente, incluindo:

* Data e hora;
* Usuário responsável;
* Operação realizada;
* Endereço IP da requisição.

Utilize o campo **Lista de ações** para localizar registros específicos.

![](https://files.readme.io/742c9858d1a407e73344f99ba1338c9e920d225ab6b9d73c948b10a86cbdb63b-Lista_de_aes_-_hitrico.png)

## Informações registradas

Dependendo da operação realizada, o histórico poderá apresentar informações adicionais, como:

* Produtos e microsserviços impactados;
* Carteira digital alterada;
* Microsserviço alterado;
* Detalhes da operação realizada.

<Callout icon="📘" theme="info">
  ### Importante

  O Histórico de ações reúne registros de configurações, microsserviços, carteiras digitais e demais funcionalidades disponíveis na Gestão API E-commerce.
</Callout>
