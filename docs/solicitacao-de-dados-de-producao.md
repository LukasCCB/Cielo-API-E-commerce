# Solicitação de dados de produção

Para finalizar o processo, é necessário **validar os passos** das etapas anteriores e então **solicitar as credenciais de acesso** para entrar em produção.

### 1. Branding guideline

Verifique se todas as diretrizes de branding foram seguidas conforme descrito no <a href="https://developers.google.com/pay/api/android/guides/brand-guidelines" target="_blank">Guia Diretrizes de Marca</a>.

### 2. Checklist

Verifique se todos os itens do <a href="https://developers.google.com/pay/api/android/guides/test-and-deploy/integration-checklist" target="_blank">checklist de integração</a> foram atendidos.

### 3. Solicitação de credenciais

Após tudo validado, solicite os dados de acesso do ambiente de produção para o <a href="https://docs.cielo.com.br/ecommerce-cielo/page/atendimento" target="_blank">atendimento</a>.
