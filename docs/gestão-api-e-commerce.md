# Gestão API E-commerce

<Callout icon="⚠️" theme="warn">
  ### Acesso à funcionalidade

  Disponível apenas para estabelecimentos (EC) com contratação da solução API E-commerce.

  Se necessário, use **Trocar estabelecimento** para selecionar outro EC.
</Callout>

<Callout icon="ℹ️" theme="info">
  ### Permissões necessárias

  As configurações indicadas só podem ser realizadas por usuários com permissões de **Administrador** ou **Analista**.

  Para gerenciar permissões de acesso, acesse **Meu cadastro >&#x20;**<Anchor target="_blank" href="https://docs.cielo.com.br/ecommerce-cielo/docs/gestao-de-acessos">**Gestão de acessos**</Anchor>.
</Callout>

A **Gestão API E-commerce** reúne os recursos necessários para administrar a integração do seu estabelecimento com as APIs E-commerce da Cielo.

Nesta área, é possível **configurar parâmetros da integração, gerenciar carteiras digitais, administrar microsserviços e consultar o histórico de ações** do ambiente.

## Como acessar

1. Acesse o <Anchor target="_blank" href="https://www.cielo.com.br/">Site Cielo</Anchor>;
2. Selecione o estabelecimento (EC) desejado;
3. No menu superior, clique em **E-commerce**;
4. Acesse **Gestão API E-commerce**.

> Caso a opção **Gestão API E-commerce** não esteja disponível, verifique se o EC selecionado possui contratação da solução.
