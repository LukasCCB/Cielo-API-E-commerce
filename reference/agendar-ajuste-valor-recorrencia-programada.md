# Agendar atualização de valor na recorrência programada

Permite agendar alterações no valor de uma assinatura recorrente, possibilitando a loja programar ajustes futuros para uma data específica.

Exemplos de uso:

* Aplicação de promoções periódicas;
* Reajustes sazonais;
* Reajustes anuais.
