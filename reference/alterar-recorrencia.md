# Alterar dados da recorrência

> ℹ️
>
> Saiba mais sobre essa funcionalidade <a href="https://docs.cielo.com.br/ecommerce-cielo/docs/recorrencia#tipos-de-recorr%C3%AAncias"
> target="\_blank">na documentação</a>.

É possível alterar os seguintes dados de uma transação recorrente:

* Dados do comprador;
* Dados do pagamento;
* Valor da recorrência;
* Dia da recorrência;
* Data do próximo pagamento;
* Intervalo da recorrência;
* Data final da recorrência.
