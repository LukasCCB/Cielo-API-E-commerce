# Códigos de retorno de captura 

| **Código** | **Descrição**                                                       |
| ---------- | ------------------------------------------------------------------- |
| 00         | Transação capturada com sucesso                                     |
| 002        | Credenciais inválidas                                               |
| 003        | Venda não encontrada                                                |
| 841        | O status da transação não permite realizar captura                  |
| 842        | O valor da captura deve ser igual ou menor que o valor da transação |
| 843        | A data máxima para a captura está expirada                          |
| 999        | Captura não realizada por falha sistêmica                           |
