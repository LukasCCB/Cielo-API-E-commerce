# Ambientes e coleções

## Criando Environment Cielo

O primeiro passo na utilização do postman é a criação do ambiente (environment) da API. Essa configuração vai definir quais credenciais e endpoints serão utilizados como padrão, assim evitando a necessidade de realizar configurações a cada teste.

## Importando uma Collection

A Cielo dispõe de [coleções padrões](https://docs.cielo.com.br/ecommerce-cielo/reference/collections-e-environments-cielo) para suas APIs. Você pode importa-las diretamente para o seu Postman e ter todos os exemplos prontos para utilização instantaneamente, sem a necessidade de copia-los diretamente do manual.

Siga o tutorial abaixo para importar uma coleção Cielo:
