# Atualização do script 3DS

A partir de 31/07/2026, as URLs utilizadas pelo JavaScript do 3DS passarão a contar com um novo mecanismo de validação de integridade.&#x20;

Clientes que utilizam uma cópia local do script JavaScript do 3DS devem **atualizar sua integração até 31/07/2026**, utilizando a [versão disponível na documentação](https://docs.cielo.com.br/ecommerce-cielo/docs/implementando-script). Após essa data, versões antigas poderão deixar de funcionar.

Clientes que carregam o script **diretamente pelos servidores da Cielo** não precisam executar nenhuma ação, pois a atualização ocorrerá automaticamente.
