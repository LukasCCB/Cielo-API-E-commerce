# Maio de 2026

Acompanhe as últimas atualizações da API E-commerce Cielo.

## 🚀Novidades

Confira os novos recursos que adicionamos para melhorar sua experiência.

* **Suporte a CNPJ alfanumérico**:

A API passa a aceitar CNPJs alfanuméricos, em conformidade com a Receita Federal, que iniciará a emissão desse novo formato a partir de julho. Os campos que recebem CNPJ foram padronizados para o tipo Alfanumérico (string), substituindo o formato numérico. Mantido o tamanho fixo de 14 caracteres.

## 🛠️ Melhorias

* **Inclusão de limites para os campos do header do [webhook (POST de notificação)](https://docs.cielo.com.br/ecommerce-cielo/docs/webhook)**:
  * Key: até 256 caracteres;
  * Value: até 1500 caracteres.
* **Atualização da [tabela ABECS](https://docs.cielo.com.br/ecommerce-cielo/page/abecs) com informações adicionais sobre os códigos Mastercard 79, 82 e 83:**
  * Os códigos estão associados ao Merchant Advice Code (MAC);
  * O comportamento pode variar conforme a operadora.
* **Inclusão de orientações para ativação conjunta da [tokenização de bandeira](https://docs.cielo.com.br/ecommerce-cielo/docs/network-token#integra%C3%A7%C3%A3o-facilitada-cielo) (Visa e Mastercard) com a tokenização Cielo (cartão protegido):**
  * Especifica como habilitar a funcionalidade para que o token da bandeira seja exibido no extrato, substituindo o número do cartão original.
