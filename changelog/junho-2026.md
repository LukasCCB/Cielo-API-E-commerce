# Junho de 2026

Acompanhe as últimas atualizações da API E-commerce Cielo:

## 🛠️ Melhorias

* Novo código [MAC 45 da Mastercard na tabela](https://docs.cielo.com.br/ecommerce-cielo/reference/retentativa-bandeira#mastercard) de retentativas (a partir de 23/10/2026):
  * Inclusão do **MAC 45** no tópico "Merchant Advice Code Transaction Excellence (MAC)": indica que a transação Maestro PIN-less foi negada, mas pode ser aprovada ao reenviar com **inserção do PIN**;
  * Válido para transações de **débito e pré-pago** (Maestro). Vigência: a partir de 23/10/2026.

* Bandeira Elo disponível para tokenização de bandeira facilitada:
  * **Elo** passa a estar disponível para[ tokenização facilitada.](https://docs.cielo.com.br/ecommerce-cielo/docs/network-token#integra%C3%A7%C3%A3o-facilitada-cielo)
